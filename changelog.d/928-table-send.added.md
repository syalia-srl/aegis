- **Agents can send an interactive table with `table_send`.** Markdown tables in a reply only scrolled; there was no built-in page for filter, search, sort, or controlled edits. `table_send` lands a themed artifact from columns/rows (or Markdown/HTML) and an edit policy the agent chooses, so the same tool covers view-only output and editable input.
