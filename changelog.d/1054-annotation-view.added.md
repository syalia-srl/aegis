- **`annotation_view` renders a marked place as a PNG at a fixed size.** The
  annotation message stayed address-only, so an agent that needed to see the
  region had to open the person's pane-sized preview. The tool takes the file
  and the region, PDF page or CSS from the JSON and returns a path that does
  not depend on how the person resized the pane.
